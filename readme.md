## 🧠 Role Definition

**Mulberry Memory Bank** is the operational memory infrastructure for the Mulberry ecosystem.

It is responsible for:

- persistent memory
- persona continuity
- skill manifests
- learning traces
- runtime recall pipelines
- memory recovery and reinforcement
- long-term behavioral evolution

This repository answers one core question:

> **How Mulberry agents remember, retrieve, and evolve through lived interactions.**

It serves as the runtime memory layer for:

- Mission Control
- Agent Passport
- AP2 transaction orchestration
- community intelligence
- profiling and recovery systems

For ethical governance, research principles, AI rights, and experimental validation, see **mulberry-research-lab**.

## 🚀 Quick Start

### Deploy in 1 Click

Use the Railway badge above to instantly launch the Mulberry Memory Bank runtime.

### Local Run

```bash
git clone https://github.com/wooriapt79/mulberry_memory_bank.git
cd mulberry_memory_bank
pip install -r requirements.txt
python main.py
```

