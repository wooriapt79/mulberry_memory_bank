- AI 시장 구조 변화 및 플랫폼 경쟁 분석
- 에이전트 경제(Agentic Economy) 트렌드 관측
- 검색 게이트웨이 모델 전환 (Google AI Overviews, Perplexity 등)
- 기술 패러다임 전환이 Mulberry 전략에 미치는 함의
- 외부 연구 논문·보고서 기반 인사이트
