## 발견된 문제 (에러 목록)

### 1. arxiv 논문 수집 미작동
- **증상**: `daily_hunts/` 파일에 논문이 없고 `http://arxiv.org` URL만 저장됨
- **원인 A**: API 엔드포인트 오류 — `http://export.arxiv.org` (홈페이지) 호출
- **원인 B**: XML 네임스페이스 오류 — `{http://www.w3.org}` (잘못됨)
- **원인 C**: arxiv 쿼리 인코딩 오류 — `"+OR+"` → requests가 `%2BOR%2B`로 인코딩
- **수정**: `scripts/arxiv_hunter.py` 신규 작성
  - 올바른 엔드포인트: `http://export.arxiv.org/api/query`
  - 올바른 네임스페이스: `{http://www.w3.org/2005/Atom}`
  - 올바른 쿼리: `" OR "` 사용

### 2. yfinance 시장 데이터 미사용
- **증상**: 브리핑에 `"$Market Status Checked"` 하드코딩 값
- **수정**: `scripts/lynn_memory_writer.py` 내 `get_market_data()` 함수 — yfinance 실제 연동

### 3. UnicodeEncodeError (cp949) — 총 3건
- **증상**: Windows 환경에서 `✅`, `—` (em dash) 출력 시 크래시
- **수정**: print 문의 이모지/em dash 제거 또는 `-` 대체
- **파일**: `lynn_memory_writer.py`, `lynn_risk_logger.py`

### 4. training_logs 자동화 미연결
- **증상**: `scripts/lynn_risk_logger.py` 존재하지만 워크플로우에서 호출 안 됨
- **수정**: `lynn_daily_write.yml`에 `Run Risk Logger` 스텝 추가 + `training_logs/` git add 포함

### 5. agent_activity.md 중복 항목

- **수정**: 중복 제거 후 단일 항목으로 정리 + Phase 1 가동 비고 추가
